# 안저 데이터 기반 미세혈관 노화 지표 및 양안(Bilateral) 검증 플랫폼

> **배포 웹사이트**: [GitHub Pages 데모](https://khwan08.github.io/retinal-vessel-analysis/)  
> **연구 보고서**: [안저노화추정.pdf](./안저노화추정.pdf)

---

## 1. 연구 개요 및 핵심 가설
- **데이터셋**: Kaggle EyePACS 35,126안 / 17,563명 (환자 실제 나이 라벨 부재)
- **핵심 문제 의식**: EyePACS에는 실제 나이(세)가 없으므로 억지 나이 회귀 모델을 학습하는 대신, **사진에서 직접 측정 가능한 미세혈관 지표(Vessel Morphometry)**를 정량화하고 **양안(Bilateral) 구조**로 재현성과 질환(DR) 왜곡을 검증함.
- **주요 발견**:
  1. 혈관 지표가 사진 화질(대비·선명도)과 0.75~0.88로 상관되어 화질을 재고 있던 문제를 극복하기 위해 **화질 보정 혈관 노화 지수(Quality-adjusted Aging Index)** 개발.
  2. 정상안 양안 재현성: 급내상관계수  = 0.63$.
  3. 사람 간 DR 차이는 -0.19 SD/단계이나, 같은 사람 두 눈 비교에서는 -0.03 SD/단계로 급감 -> 병변이 혈관 검출을 교란함을 입증.
  4. 당뇨망막병증(DR) 5등급 판독: 환자 단위 5-fold 교차검증 (단안 QWK 0.497, 양안 QWK 0.526).

## 2. 웹 대시보드 화면 구성
1. **판독 사례 (#cases)**: 12명 환자 양안 사진 및 혈관 검출 마스크 즉시 토글, 정상 눈 대비 백분위 바, 측정 잡음 비교.
2. **혈관 노화 지표 (#index)**: 화질 보정 선형회귀 및 포레스트 플롯(Forest Plot).
3. **DR 판독 모델 (#dr)**: 환자 단위 5-fold 혼동행렬 및 단안/양안 모델 성능 비교.
4. **양안 분석 (#bilateral)**: 17,563쌍 좌·우 5x5 등급 교차표, 일치율 87.25%, QWK 0.855.
5. **데이터와 한계 (#limits)**: 전 파이프라인 단계별 산출물 및 학술적 한계 명시.
